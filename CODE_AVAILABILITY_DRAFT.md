# Code Availability statement draft

The analysis code supporting the findings of this study will be made available in a public GitHub repository and archived in Zenodo with a version-specific DOI. The repository contains analysis scripts and documentation only; it does not contain UK Biobank participant-level data, genotype data, individual-level derived data, or restricted disease outcome files. UK Biobank data are not publicly shared and remain accessible only to researchers approved under the UK Biobank access procedures.

Replace the following placeholders after the repository has passed the required UK Biobank review and the Zenodo record has been published:

- GitHub repository: `[PUBLIC_GITHUB_URL]`
- Zenodo version-specific DOI: `[ZENODO_VERSION_DOI]`
- Software license: `[LICENSE]`

Do not submit this draft with placeholders. Confirm the final wording with the corresponding author and check the current Nature Communications policy and UK Biobank terms.
